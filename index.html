✨ v0.3.0 核心优化特性回顾
  • 修复 SPA 路由进入不加载：泛匹配规则（*://panstar.ai/* 与 *://akile.ai/*）结合原生 History AOP 代理（pushState/replaceState），从控制台任何子页面跳转进入市场均能即时激活，免除手动 F5 刷新。
  • 骨架屏数据自愈机制：彻底根除过早标记 xrvDone 导致异步数据返回时失效的严重 Bug，通过数据指纹（Signature）与状态机响应式自愈。
  • 二手 VPS 科学价值模型：清晰计算溢价/折价额（倒贴多少）、折扣率、接手实际日均持有成本与 5 级折溢价徽章。
  • 彻底终结被墙低价机霸屏：在所有价值排序模式中引入 1 亿权重 IP 状态惩罚（ipPenalty），确保正常可用机器严格排在最前，被墙机自动沉底。
  • 一键快捷筛选：支持「隐藏被墙 IP」与「只看折价(倒贴)机」，纯 CSS 控制显隐，零 DOM 移动损耗。
  • 现代 HUD 控制台与实时看板：顶部集成精致悬浮控制栏与实时统计看板（总台数、可用机、异常机、倒贴捡漏机），适配明暗主题。
